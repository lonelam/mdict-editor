MDict Editor — Windows portable

使用方法
1. 将整个压缩包解压到一个可写目录。
2. 双击 mdict-editor.exe 启动，无须安装本应用、Node.js 或 Rust。
3. 通过“打开 / 追加文件”选择词典或资源。
4. 跨天校对请点击“保存项目”；下次通过“打开项目”继续编辑。

运行要求
需要 Microsoft Edge WebView2 Runtime。若启动失败且系统未安装该运行时，
请从微软官网下载并安装 Evergreen Runtime：
https://developer.microsoft.com/microsoft-edge/webview2/#download-section

浏览器缓存使用当前用户的应用数据目录。项目文件和导出词典由用户选择保存位置。
项目引用原始词典路径，请保留原词典及路径。
